# 전체 자료 질의 운영

`/ai`의 “전체 노트에 질문하기”는 저장된 노트와 지원되는 첨부 자료(PDF, PNG/JPEG/WebP/HEIC/HEIF, XLS/XLSX)만 근거로 답합니다. 키, 원본, 질문은 브라우저에 보관하지 않으며 Gemini 호출은 Worker에서만 이뤄집니다.

## 시작하기

1. 최신 마이그레이션을 적용합니다.
2. Worker secret `GEMINI_API_KEY`를 등록합니다. 로컬에서는 `.dev.vars`에만 넣습니다.
3. `/ai`에서 “대기 자료 처리 이어가기”를 눌러 기존 자료를 처리하거나, 정기 동기화가 처리하도록 둡니다.

키 또는 유효한 가격 정책이 없으면 유료 호출은 시작되지 않습니다. 화면에는 키 값이나 원본 텍스트가 표시되지 않습니다.

## 처리와 근거

- 노트는 블록 단위로, PDF는 페이지 단위로, 엑셀은 모든 시트(숨김 시트 포함)의 셀 묶음으로 나눠 이어서 처리합니다.
- 이미지와 스캔 PDF는 전사 결과에 불확실성 경고가 있으면 확정 사실과 계산에 쓰지 않습니다.
- 질문은 열린 문서가 아니라 처리된 전체 자료를 대상으로 합니다. 자료가 많으면 검색어 기반으로 선택한 구간만 검토하므로, 결과의 범위 안내를 함께 확인해야 합니다.
- 모든 표시된 사실에는 원문 인용과 원본 링크가 필요합니다. 인용이 맞지 않거나 자료가 답변 중 수정·삭제되면 해당 결과를 표시하지 않습니다.
- 계산은 모델이 아닌 서버가 확인된 원문 숫자로 수행합니다. 수식 셀의 저장 결과와 불확실한 전사 값은 계산에서 제외합니다.

## 예산과 장애 처리

월 한도는 한국시간 기준 전체 사용자 합산 30,000원입니다. 호출 전 보수적으로 예산을 확보하고, 사용량을 확인하지 못한 호출은 확보액을 유지합니다. 따라서 호출 실패 뒤에도 잔여 예산이 즉시 돌아오지 않을 수 있습니다.

가격 정책은 `ai_prices` 테이블에서 관리합니다. 만료되었거나 안전성 검증을 통과하지 못한 정책이면 호출은 보류됩니다. 운영자는 만료 전에 현재 모델 가격·환율 정책·안전 계수를 검토한 뒤 새 행을 추가하고 기존 행을 비활성화해야 합니다.

처리 실패는 자료 처리 현황에 남습니다. 원본을 고치거나 지원 형식으로 변환한 뒤 “다시 대기열에 넣기”를 사용하세요. 예산 대기는 다음 달에 자동으로 다시 시도할 수 있습니다.

## 서버 지역 오류

Google이 `User location is not supported`를 반환하면 서버 요청의 지역 판정으로 거절된 것입니다. `wrangler.toml`의 `placement.region = "aws:ap-northeast-2"`로 서울 인근 실행 위치를 요청합니다. 이 설정을 지원하는 Wrangler 4로 배포해야 합니다.

Placement는 국가나 외부 통신 IP를 보장하지 않는 위치 힌트입니다. 배포 후 실제 질문 성공 여부를 확인해야 하며, 예약 작업의 실행 위치까지 동일하다고 가정하지 않습니다. 자동 첨부 처리에서만 지역 오류가 나면 `/ai`의 수동 처리에서도 비교 확인합니다. 계속 거절되면 Google/Cloudflare에 서버 IP 지역 판정 문제를 확인하거나, Gemini 지원 지역에 고정 배치할 수 있는 별도 AI 서버가 필요합니다.

공식 문서: [Cloudflare Placement](https://developers.cloudflare.com/workers/configuration/placement/), [Gemini 지원 지역](https://ai.google.dev/gemini-api/docs/available-regions).
